# Mission Control 2.2 — Live Google Calendar

This update makes Google Calendar events actually appear in:

- Today's Focus
- Mission Control Index calculations
- The main calendar
- Future Phil suggestions

After deployment:
1. Open Mission Control.
2. Press Google Calendar → Sync, or Sync all.
3. Upcoming Google events will be merged into the shared event engine.

The connection token remains stored securely in the HTTP-only cookie.
